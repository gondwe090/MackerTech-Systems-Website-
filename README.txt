MACKERTECH SYSTEMS WEBSITE
========================

CONTENTS
--------
index.html          Home page
about.html          About page
services.html       Services page
projects.html       Projects / portfolio page
contact.html        Contact page
css/style.css       Main stylesheet
js/main.js          Navigation and contact-form JavaScript
assets/             Your supplied MackerTech logo images

HOW TO PREVIEW
--------------
1. Extract the ZIP file.
2. Open the MackerTech_Systems_Website folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Use the navigation links to open the other pages.

IMPORTANT BEFORE PUBLISHING
---------------------------
1. Your email, WhatsApp/call number, Facebook, and TikTok links have been added.
2. Your location is set to Chichiri 3, Blantyre, Malawi, with your supplied Google Maps link.
3. Replace the sample portfolio cards in projects.html with real project details and images.
4. Review the About page and add your actual company history, mission, and team details.

CONTACT FORM
------------
The contact form is front-end only. Once you add the real company email in js/main.js,
it prepares an email using the visitor's email application (mailto). It does not store
messages in a database or send messages silently from the website. For a server-based
contact form, connect a backend or a form service before launch.

DESIGN
------
White is the main background. Bright blue is used for branding and highlights, with
black/dark navy text. The site is responsive for phones, tablets, and desktop screens.

HOSTING
-------
This is a static HTML/CSS/JavaScript website. It can be published using a static host
such as GitHub Pages, Netlify, or Cloudflare Pages. A custom domain can be connected
through the hosting provider.
